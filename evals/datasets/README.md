# Evaluation Datasets

This directory contains evaluation and test cases for SupportPilot AI features.

## Purpose

- **Regression testing** — Ensure prompt/model changes don't degrade quality
- **Benchmarking** — Compare model versions and prompt iterations
- **Development fixtures** — Realistic examples for local development

## Format (future)

Datasets will be structured JSON or YAML files containing support ticket scenarios with expected outputs (classification, draft response, etc.).

## Current Status

No datasets yet. Support ticket evaluation datasets will be built separately.
