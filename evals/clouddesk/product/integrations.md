# Integrations

## Slack

Available on all plans.

Common setup:
1. Open organization integrations.
2. Select Slack.
3. Authorize CloudDesk.
4. Select permitted channels.
5. Test the connection.

## Google Drive

Available on Professional and Enterprise.

Requires Google authorization and appropriate organization permissions.

## GitHub

Available on Professional and Enterprise.

Requires GitHub authorization and repository access.

## Microsoft Teams

Available on Professional and Enterprise.

Requires Microsoft authorization and appropriate tenant permissions.

If an integration is authorized but events are not arriving, check authorization status, permissions, selected resources, and webhook/event configuration before escalating.
