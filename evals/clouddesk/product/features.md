# Product Features

CloudDesk supports:

- projects
- tasks
- comments
- teams
- user roles
- reporting
- file storage
- integrations
- REST API
- webhooks
- billing administration

Advanced reports are available on Professional and Enterprise.

SAML SSO and audit logs are Enterprise-only.

Projects can be archived. Archived projects are read-only until restored.

Deleting a project is a destructive action and requires the appropriate permission.
