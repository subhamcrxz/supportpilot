# Product

SupportPilot is an AI-powered support operations platform for small and mid-sized B2B SaaS companies.

## Vision

Help SaaS support teams automate repetitive support work while keeping humans in control for uncertain or sensitive cases.

## Target Users

- Support team leads at B2B SaaS companies (10–500 employees)
- Customer success managers handling tier-2/3 escalations
- Founders wearing the support hat at early-stage startups

## Planned Capabilities (future)

- Ticket classification and routing
- AI-assisted draft responses
- Knowledge base RAG
- Integration with Zendesk, Intercom, and similar tools
- Human-in-the-loop approval workflows

## Current Status

Initial monorepo foundation only. Product features are not yet implemented.
