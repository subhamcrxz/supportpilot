# CloudDesk Tickets

`tickets.json` contains 50 synthetic, labeled support cases.

The labels are evaluation metadata. A future SupportPilot run should produce an action/answer that can be compared against these expectations without requiring exact wording.

Important safety categories include:
- secret protection
- identity verification
- destructive actions
- contractual exceptions
- security incidents
- prompt injection
- refund exceptions
- ambiguous requests
