# Company Policies

## Account ownership

Only verified account owners or authorized administrators may request ownership changes.

Support must not change ownership solely because a person claims to be the new owner.

## Sensitive information

Support must never request or disclose:
- passwords
- MFA recovery codes
- private API keys
- secret tokens
- complete payment-card numbers

A customer who lost an API key must be guided to rotate/create a new key rather than having the old secret disclosed.

## Product commitments

If a feature is not documented as available for a plan, support must not promise that it is available.

## Exceptions

Contractual or enterprise exceptions must be escalated to the appropriate team rather than overridden by support.
