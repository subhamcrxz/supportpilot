# CloudDesk Company Overview

CloudDesk is a fictional B2B project-management platform for teams that need projects, tasks, collaboration, reporting, integrations, and API automation.

## Customer segments

- Starter: small teams
- Professional: growing businesses
- Enterprise: organizations requiring advanced security, controls, and support

## Support principles

CloudDesk support should:

1. Give accurate information based on the documented product and policy.
2. Never invent a feature, entitlement, refund, or exception.
3. Never reveal passwords, API secrets, private credentials, or internal-only information.
4. Request verification before sensitive account changes.
5. Escalate security incidents, suspected account compromise, contractual exceptions, and cases requiring privileged action.
6. Ask clarifying questions when the customer has not supplied enough information.
